# Contributing Guidelines

Thank you for your interest in improving the YouTube Downloader Suite!

## 1. How to Report Bugs
Please open an issue with:
- The exact URL that caused the issue.
- The terminal output/error message.
- Your `yt-dlp` version (run `yt-dlp --version`).

## 2. Proposing Features
Open an issue first to discuss the design before submitting code changes.

## 3. Development Workflow
1. Fork the repository.
2. Create a feature branch (`git checkout -b feature/AmazingFeature`).
3. Commit changes (`git commit -m 'Add AmazingFeature'`).
4. Push to the branch (`git push origin feature/AmazingFeature`).
5. Open a Pull Request.

## 4. Pre-submission Checklist
- Ensure scripts execute correctly in standard CMD/PowerShell.
- Validate that no hardcoded absolute paths leak into commits.
